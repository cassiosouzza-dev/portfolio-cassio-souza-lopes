# Portfólio Pessoal — Cássio de Souza Lopes

Portfólio online desenvolvido para a atividade prática da disciplina **Fundamentos da Programação Web** (Uninter).

## Tecnologias

- HTML5
- CSS3 (puro, sem frameworks)
- JavaScript (puro, sem bibliotecas/frameworks)

## Estrutura do projeto

```
├── index.html        # Página única, com as 4 seções via navegação por âncoras
├── css/
│   └── style.css      # Estilos, variáveis de tema (claro/escuro) e responsividade
├── js/
│   └── script.js       # Tema claro/escuro, menu mobile e validação do formulário
└── README.md
```

## Funcionalidades

- Menu de navegação fixo com âncoras para as seções: Sobre mim, Formação, Portfólio e Contato.
- Menu responsivo (hambúrguer) para dispositivos móveis.
- Alternância entre tema claro e escuro, com preferência salva no navegador.
- Formulário de contato com validação em JavaScript (campos obrigatórios e formato de e-mail) e simulação de envio com mensagem de confirmação.
